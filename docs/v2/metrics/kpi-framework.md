# KPI Framework (V2)

## Product KPIs
- Activation rate (first successful core action).
- D1 retention.
- D7 retention.
- Core flow conversion per feature (`auth`, `chat`, `payments`).

## Reliability KPIs
- Crash-free sessions.
- API error rate.
- p95 backend latency by endpoint.
- p95 UI frame/render duration for critical screens.

## UX KPIs
- Time to first success.
- Task abandonment rate.
- Funnel drop-off per step.

## Governance
- Every new feature must declare KPI impact and expected direction.
- Rollouts require pre/post metric snapshots.
