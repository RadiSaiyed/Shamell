# V2 Interaction Principles

## Core behavior
- Keep actions short and reversible.
- Show progress and outcomes immediately.
- Use positive feedback loops (streak/progress) without manipulation.

## Retention strategy
- Personalized quick actions on home.
- One-tap return to recent high-value actions.
- Contextual reminders based on explicit user signals.

## Guardrails
- No deceptive timers.
- No hidden opt-ins.
- No value-less notification bursts.
