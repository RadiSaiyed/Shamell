# V2 Design System Baseline

## Tokens
Implemented in `clients/shamell_flutter/lib/v2/design/tokens.dart`.

- Color primitives (`brand`, `accent`, `surface`, `card`, `textPrimary`)
- Spacing scale (`xs`..`xl`)
- Radius scale (`md`, `lg`)

## Components
Implemented in `clients/shamell_flutter/lib/v2/design/components`.

- `V2SurfaceCard`
- `V2PrimaryButton`
- `V2StatusPanel`

## Motion
Implemented in `clients/shamell_flutter/lib/v2/design/motion.dart`.

- Fast/normal/slow durations
- Emphasized curve for meaningful transitions
